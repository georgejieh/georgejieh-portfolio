# George Jieh — Portfolio Website

AI/ML developer portfolio built with Astro and Tailwind CSS. Hosted at [georgejieh.dev](https://georgejieh.dev).

## Tech Stack

- [Astro](https://astro.build/) — web framework for content-driven sites
- [Tailwind CSS](https://tailwindcss.com/) — utility-first CSS
- [GitHub Pages](https://pages.github.com/) — hosting via GitHub Actions

## Local Development

```bash
yarn install
yarn dev
```

## Build

```bash
yarn build
yarn preview
```

## Deployment

Automatically deployed to GitHub Pages when changes are pushed to the main branch.
